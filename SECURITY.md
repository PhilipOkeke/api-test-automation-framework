# Security Policy

## Supported version

Security fixes apply to the latest version on the main branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email **Engr.philipokeke@gmail.com** with the affected component, reproduction steps, impact, and any suggested mitigation.

You can expect an acknowledgement within five business days. Please allow reasonable time for investigation and remediation before public disclosure.

## Scope

Reports involving exposed credentials, unsafe request handling, dependency vulnerabilities, or CI/CD configuration are especially helpful. Never include real production secrets or customer data in test fixtures or reports.
